# CA証明書バンドル

`cacert.pem`は、curlプロジェクトがMozillaのCA証明書ストアから生成して公開している
PEM形式のCAバンドルです。

macOS配布版では、このファイルをAPI、GB Media Relay、N64 Media RelayのTLS証明書検証に
使用します。
